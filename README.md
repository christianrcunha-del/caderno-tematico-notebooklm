# 🎯 Contexto e Objetivos

Este repositório foi desenvolvido com o objetivo de acelerar o aprendizado da linguagem Python por meio de exercícios práticos, desafios de programação e repetição estratégica dos comandos mais utilizados.

A proposta principal é reduzir o tempo necessário para aprender programação, utilizando Inteligência Artificial e métodos de prática contínua para otimizar a fixação do conteúdo.

## Objetivos de Estudo

- Aprender Python de maneira mais rápida e eficiente;
- Praticar comandos básicos e avançados;
- Desenvolver lógica de programação;
- Resolver desafios práticos;
- Memorizar comandos e suas funcionalidades;
- Utilizar IA como apoio nos estudos;
- Criar um material reutilizável para revisões futuras.

# 📘 Miniguia de Estudo

## 📌 Variáveis

Utilizadas para armazenar valores na memória.

```python
nome = "Python"
idade = 25
```

---

## 📌 Condicionais

Permitem criar decisões no programa.

```python
if idade >= 18:
    print("Maior de idade")
else:
    print("Menor de idade")
```

---

## 📌 Estruturas de Repetição

Executam comandos repetidamente.

```python
for i in range(5):
    print(i)
```

---

## 📌 Funções

Blocos reutilizáveis de código.

```python
def saudacao():
    print("Olá")
```

---

# 📖 Glossário

| Termo | Definição |
|---|---|
| Variável | Espaço para armazenar dados |
| Loop | Estrutura de repetição |
| Condicional | Estrutura de decisão |
| Função | Bloco reutilizável de código |
| Lista | Coleção de elementos |
